# PyTorch 模型训练学习笔记

> 配套示例:`mnist_train.py`(MNIST 手写数字识别,CNN)

## 一、训练一个模型的 5 个固定步骤

无论什么任务(图片分类、语音识别、文本生成),训练流程都是这五步:

```
1. 定超参数 → 2. 准备数据 → 3. 定义模型 → 4. 训练循环 → 5. 保存模型
```

## 二、核心概念速查

| 概念 | 一句话理解 | 对应代码 |
|---|---|---|
| 张量 Tensor | 多维数组,深度学习的基本单位 | `torch.randn(2, 3)` |
| 自动求导 autograd | 自动计算每个参数的梯度(导数) | `loss.backward()` |
| Dataset | "取一份数据"的接口 | `datasets.MNIST(...)` |
| DataLoader | 批量加载 + 打乱 + 多进程 | `DataLoader(ds, batch_size=64, shuffle=True)` |
| nn.Module | 所有模型的基类,包含参数 | `class CNN(nn.Module)` |
| 损失函数 Loss | 预测和真实值差多少 | `F.cross_entropy(outputs, labels)` |
| 优化器 Optimizer | 根据梯度更新参数 | `torch.optim.Adam(...)` |
| epoch | 完整看一遍训练集 | `for epoch in range(EPOCHS)` |
| batch | 一次喂给模型的数据量 | `BATCH_SIZE = 64` |

## 三、训练循环的四行核心代码(最重要!)

```python
outputs = model(images)         # ① 前向传播:输入 → 预测
loss = F.cross_entropy(...)     # ② 计算损失:预测与真实差距
loss.backward()                 # ③ 反向传播:计算每个参数的梯度
optimizer.step()                # ④ 参数更新:沿梯度反方向走一步
```

- ①③ 由 PyTorch 自动完成,② 由你选择损失函数,④ 由优化器决定怎么走
- `optimizer.zero_grad()` 每次必须调用:清空上一步的梯度,否则会累加

## 四、CNN 结构怎么看(以 mnist_train.py 为例)

```
输入 (1, 28, 28) 灰度图
  ↓ conv1: 32 个 3×3 卷积核  → 提取低级特征(边缘、笔画)
  ↓ maxpool 2×2              → 尺寸减半: 28→14
  ↓ conv2: 64 个 3×3 卷积核  → 提取高级特征(形状、部件)
  ↓ maxpool 2×2              → 尺寸减半: 14→7
  ↓ 展平: 64×7×7 = 3136
  ↓ fc1: 3136 → 128          → 全连接组合特征
  ↓ fc2: 128 → 10            → 输出 10 个数字的得分
```

规律:**卷积层提特征(通道数越来越多)、池化层降尺寸、全连接层做分类**。

## 五、看训练输出(怎么判断模型好坏)

```
Epoch 1/5 | 训练损失 0.1234 | 训练准确率 0.9500 | 测试准确率 0.9700
```

- **训练损失**下降 → 模型在学习 ✅
- **测试准确率**比训练准确率高/接近 → 泛化良好 ✅
- 训练准确率远高于测试准确率 → **过拟合**(记死训练集,没见过的新数据表现差)
- 两者都不涨 → 学习率太大/太小、数据没处理好、模型太简单

## 八、实战案例:为什么我的手写图预测不准?

> 场景:自己画了个"2"(白底深字 PNG),模型却预测成 3 / 1,置信度还忽高忽低。

### 根因:输入与训练数据的"分布不匹配"

模型只在它见过的数据分布上表现好。喂它没见过的"风格",再好的模型也会乱猜。

| 问题 | 你的图 | MNIST 训练样本 | 后果 |
|---|---|---|---|
| 颜色方向 | 白底深色笔迹 | 黑底白色笔迹 | 模型看到的是"负片" |
| 透明通道 | RGBA(含 alpha) | 纯灰度 | `convert("L")` 忽略 alpha,笔迹变淡 |
| 笔画粗细 | 1~2 像素 | 3~4 像素,占画面 10~25% | 28×28 下细笔画≈噪声 |

### 修复:专业预处理管线(见 predict.py 的 load_user_image)

```
① 透明通道合成到白底     RGBA → 白底 RGB(alpha 作蒙版)
② 反色                  背景偏亮 → 255 - arr,保证黑底白字
③ 裁剪边界框            去掉多余空白,只留笔迹区域
④ 加粗笔画              MaxFilter(3) 膨胀 ×2,补到接近 MNIST 粗细
⑤ 缩放居中              长边 20px → 居中放 28×28 画布(MNIST 官方做法)
```

### 效果

```
修复前: 预测 3 ❌ (84.38%)  →  1 ❌ (13.81%)  →  修复后: 预测 2 ✅ (36.41%)
```

置信度 36% 的含义:模型"认得有点像 2,但不完全像"——输入质量仍不够好。
画得越粗、越大、越居中,置信度越高。

### 经验总结

1. **模型认错 ≠ 模型笨**,先检查输入与训练分布是否一致
2. 置信度只是"模型自己的把握",不是"正确的概率"
3. 真实项目 60~80% 的工作是预处理管线,而不是模型本身
4. **数据增强**(随机旋转/缩放/平移)让模型见过各种写法,是解决这类问题的根本手段
