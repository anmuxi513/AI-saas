# 📦 MNIST 模型交付包(方案 C:ONNX)

> 这是"把训练好的模型发给别人"的完整交付包。
> 模型本体只有一个 ONNX 文件,任何语言/平台都能加载。
> **对方不需要 PyTorch / torchvision / 训练代码 / 数据集。**

## 两种交付形态

### 形态一:exe 免安装版(推荐给不懂技术的对方)

| 文件 | 说明 |
|---|---|
| `dist/MNIST识别服务.exe` | **单文件,双击即用**(内含 Python + onnxruntime + 模型,195 MB) |

对方使用:
1. 双击 `MNIST识别服务.exe`(首次启动需等待 10~20 秒解压)
2. 自动弹出黑色窗口提示服务已启动
3. 浏览器打开 `http://localhost:8000` 即可手写识别
4. 用完关闭黑色窗口即停止

**对方不需要安装任何东西**(不需要 Python、不需要 pip)。

### 形态二:源码版(对方有 Python 环境)

| 文件 | 说明 |
|---|---|
| `mnist_cnn.onnx` | **模型本体**(结构 + 42 万权重,单文件 1.6 MB) |
| `serve.py` | 推理服务:托管网页 + `/api/predict` 接口 |
| `index.html` | 手写识别网页 |
| `start.bat` | Windows 一键启动 |

对方使用:
```bash
pip install onnxruntime     # 只需要这一个包!
python serve.py             # 或双击 start.bat
# 浏览器打开 http://localhost:8000
```

## 快速开始(当前机器)

exe 正在运行 → 浏览器打开 http://localhost:8000,在黑板上写数字 0-9,松手即识别。

## 架构(与真实项目一致)

```
浏览器 index.html                   本地服务 serve.py
┌──────────────────┐  POST /api/predict   ┌─────────────────────┐
│ 手写画板         │  {"pixels":[784个]}  │ onnxruntime         │
│ 预处理(加粗/归一化)│ ───────────────────► │ 加载 mnist_cnn.onnx │
│ 概率条形图展示    │ ◄─────────────────── │ 推理 -> 返回结果     │
└──────────────────┘   {"pred":2,"probs":[…]} └─────────────────────┘
```

- **前端**负责:画板、缩放 28x28、加粗、归一化(与训练时一致)
- **服务端**只负责:加载 ONNX、推理、返回结果
- 同一服务可以对接任意前端:浏览器、Python 脚本、Spring Boot、甚至 CesiumJS / OpenLayers 地图项目
- 模型推理走本地 HTTP 接口,数据不出本机

## 命令行推理(不开网页)

```bash
python onnx_predict.py                    # 测试集随机 10 张
python onnx_predict.py 你的图片.png       # 预测自己的图片
```

## 常见问题

- **网页提示"无法连接推理服务"?** 先运行 `python serve.py`,再刷新网页。
- **识别不准?** 笔画太细、太潦草会降低置信度,画粗一点试试。
- **置信度低?** 输入和 MNIST 训练样本"长得不一样"导致的,置信度 ≠ 正确率。
- **端口被占用?** 改 serve.py 里的 `PORT = 8000` 换一个端口。

## 技术要点(写给懂技术的人)

- 输入: `(1, 1, 28, 28)` float32,归一化 `(x/255 - 0.1307) / 0.3081`
- 输出: `logits` 形状 `(1, 10)`,softmax 后取最大概率
- 预处理:黑底白字(无需反色)+ 3x3 膨胀加粗 ×2 + 缩放 28x28
- API: `POST /api/predict`,请求 `{"pixels": [784 个归一化 float]}`,响应 `{"pred": int, "probs": [10 个 float]}`
- 重新导出模型(在 `projects/mnist` 目录): `python export_onnx.py`（本交付包内的模型是导出后的副本）
